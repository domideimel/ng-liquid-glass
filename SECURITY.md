# Security policy

## Supported versions

Only the latest release of `@domideimel/ng-liquid-glass` gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/domideimel/ng-liquid-glass/security/advisories/new) instead.

Include the affected version, a description, and steps or a minimal reproduction. You'll get an answer within a week. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.
