`[lgCard]` turns an `<article>` or `<section>` into a surface. Add `glass` for the frosted material over images or colour.

{{ NgDocActions.demo("CardDemo") }}

## Header with actions

`[lgCardHeader]` puts the card's heading on the start side and `[lgCardActions]` (a few icon buttons: copy, download, send to) on the end side, centred on the buttons. It wraps onto two rows when there's no room.
