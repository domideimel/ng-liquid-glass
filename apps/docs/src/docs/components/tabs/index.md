Tabs with automatic activation (WAI-ARIA tabs pattern). Only the selected tab is in the tab order. Tab moves into the panel; arrow keys switch tabs.

{{ NgDocActions.demo("TabsDemo") }}

## Keyboard

| Key        | Action                                      |
| ---------- | ------------------------------------------- |
| ← / →      | Previous / next tab (wraps, skips disabled) |
| Home / End | First / last tab                            |
| Tab        | Move into the panel                         |
